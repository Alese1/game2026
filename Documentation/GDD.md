# GDD — Sword Art Online: Open World & Gun Gale Online (прототип)

Одиночная игра в сеттинге SAO: обычная жизнь в современном японском районе + бои в VRMMO Gun Gale Online
(турнир Bullet of Bullets). Миры связаны общей экономикой, инвентарём и сохранениями.

## Игровой цикл

Город → прогулка, NPC → работа в офисе (кредиты) → магазин (оружие/экипировка) → квартира →
FullDive-шлем («Link Start») → лобби BoB (тир, регистрация) → матч → награда → выход из GGO в квартиру → сохранение.
Цикл бесконечно повторяем.

## Сцены

| Сцена | Назначение |
|---|---|
| `Bootstrap/MainMenu` | Стартовое меню: Новая игра / Продолжить (недоступна без сохранения) / Настройки / Выход |
| `RealWorld/City` | Район ~116×116 м: перекрёсток, 4 квартала (дом героя, магазин, офис, парк), 7 NPC |
| `Apartment/Apartment` | Квартира героя: FullDive-шлем, кровать (сохранение), ПК (новости), выход в город |
| `GGO/GGO_Arena` | Пустошь ~230×230 м с 8 зонами интереса + лобби турнира (отдельный зал) |

## Управление

| Реальный мир (3-е лицо) | GGO (1-е лицо) |
|---|---|
| WASD — ходьба, Shift — бег, Space — прыжок | WASD, Shift, Space |
| Мышь — камера (Cinemachine, ограничение pitch −35…70°) | Мышь — обзор (±85°) |
| E — взаимодействие | ЛКМ — огонь, ПКМ — прицел, R — перезарядка |
| Esc — пауза / закрыть окно | 1/2/3 и колесо — оружие, H — аптечка, Tab (удерживать) — статистика, E — терминалы, Esc — пауза |

Геймпад частично поддержан (стики, A/X/Y, триггеры).

## Реальный мир

- **Взаимодействие**: луч из центра камеры + запасной поиск перед персонажем; подсказка «[E] Действие»
  показывается только для доступных объектов; подсветка эмиссией при наведении, вспышка и звук при использовании.
- **NPC** (7): имя/роль над головой, состояния Idle / Walking (маршруты по NavMesh) / Interacting
  (останавливается и поворачивается к игроку), циклические диалоги о жизни города и VRMMO.
- **Магазин «Arms & Gear 24»**: прилавок внутри магазина. Товары с иконкой-глифом, описанием, характеристиками,
  ценой, статусом владения; проверка средств, защита от повторного списания (флаг busy + кулдаун кнопки + уникальность).
- **Работа «Nishikawa Data»** (терминал в лобби офиса): мини-игра «ввод данных» — набрать 6 кодов из 4 клавиш
  (A S D F J K L) за 35 с. Ошибка сбрасывает код. Оплата: 15 кр./код + 30 за смену + 20 без ошибок (макс. 140).
- **Торговые автоматы** (10 кр.) — маленький «сток» кредитов. **Афиша** на остановке — лор турнира.

## Квартира и FullDive

Шлем на тумбочке («E — Подключиться к Gun Gale Online»): сохранение → экран «LINK START» (кольца) →
асинхронная загрузка GGO → лобби. Выход из GGO (терминал LOG OUT, пауза, экран результата) возвращает к шлему.
Кровать — ручное сохранение, ПК — новости о турнире.

## Gun Gale Online

### Оружие (WeaponData)

| | Пистолет Viper-9 | Автомат AR-57 Strix | Снайперка Longbow-X |
|---|---|---|---|
| Цена | стартовое | 350 | 650 |
| Урон / темп | 22 / 5 в с (semi) | 18 / 10 в с (auto) | 85 / 0.9 в с (semi) |
| Магазин / запас | 15 / 4 маг. | 30 / 4 маг. | 5 / 4 маг. |
| Перезарядка | 1.3 с | 2.2 с | 3.0 с |
| Разброс бедро / прицел | 1.6° / 0.35° | 2.2° / 0.5° | 3.5° / 0.03° (оптика, FOV 18) |

Hitscan-стрельба, «bullet circle» (прицел-круг = реальный текущий разброс: движение, прыжок, отдача),
отдача камеры и модели, покачивание/sway, ADS со сменой FOV, анимация перезарядки и смены оружия, трассеры,
дульные вспышки, эффекты попаданий по типу поверхности (металл — искры, песок — пыль, бетон — крошка,
аватар — красные «полигоны»), хитмаркер, звук убийства, хедшоты (Hitbox ×2…2.5).

### Экипировка и расходники

- Бронежилет «Aegis» (300): +25 HP, −20% урона.
- Аптечка «NanoHeal» (40, до 5): +50 HP по H.
- Боекомплект «Ammo Box» (30, до 5): автоматически в начале матча, +2 магазина каждому оружию.

### Боты (BotController, State Machine)

Idle → Patrol → Detect → Chase → Attack ⇄ Cover → Reload → Dead.
Зрение с проверкой линии видимости (сквозь стены не видят), FOV и дальность по профилю, слух выстрелов,
реакция на урон, выбор дистанции (сближение/отход/стрейф), поиск укрытий (333 автоматически сгенерированных
CoverPoint), «bullet line» — красная линия прицеливания перед очередью (предупреждение игроку),
проверка дальности и LOS перед выстрелом, уход в безопасную зону. 4 профиля: Стрелок, Штурмовик, Снайпер,
Дуэлянт. Боты сражаются и друг с другом (урон бот→бот ×0.5 для темпа матча).

### Турнир Bullet of Bullets

Лобби (тир с регенерирующими мишенями, инструктор, стойки) → терминал регистрации → спавн 7 ботов,
игрок — на максимально удалённую точку → отсчёт 5 с с блокировкой управления и неуязвимостью →
бой → учёт живых, килфид, определение места → последний выживший побеждает → экран результата
(«В лобби» / «Выйти из GGO»).

### Безопасная зона

Энергетический купол (собственный шейдер: френель + сетка + пульсация), 5 этапов:
118 → 80 → 50 → 28 → 12 → 3 м; ожидание 45/35/30/25/20 с, урон вне зоны 2/4/6/10/15 HP/с.
HUD: таймер сужения, этап, предупреждение «ВНЕ ЗОНЫ» с дистанцией, фиолетовая виньетка, кольца текущей
и следующей зоны на мини-карте.

## Экономика (EconomyConfig)

Старт: 250 кр. + пистолет. Доходы: работа (до 140), турнир — участие 50, убийство 35, победа 500,
топ-3 — 100. Стартовый автомат доступен после одной смены (250 + 140 ≥ 350).

## Сохранения

JSON в `Application.persistentDataPath/savegame.json`: кредиты, инвентарь, выбранное оружие, сцена и позиция
в реальном мире, статистика (работа, турниры, победы, убийства, лучшее место, заработок).
Автосохранение: переходы между сценами, покупки, работа, турнир, выход из игры. Атомарная запись (.tmp → замена),
резервная копия .bak, карантин повреждённого файла (.corrupt) и восстановление из .bak.

## UI

Два стиля: реальный мир — спокойный синий «smart-glass», GGO — янтарно-бирюзовый военный HUD.
Все элементы строятся кодом из одного набора (UIKit) с процедурными скруглёнными спрайтами и звуками кнопок.
