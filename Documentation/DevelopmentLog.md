**Решения**
- Установлен **Cinemachine 3.1.7** (совместим с Unity 6).
- Вместо TextMeshPro используется uGUI `Text` с системным шрифтом Segoe UI (без интерактивного импорта TMP Essentials).
- UI строится кодом (`UIKit`) с процедурными спрайтами — единый стиль, нет «голых» Unity-кнопок, нет пустых ссылок.
- Звук синтезируется процедурно (`AudioService`) — у проекта есть рабочее аудио без внешних файлов.
- Сцены собираются детерминированными Editor-скриптами (меню `SwordArt/...`), запускаемыми вручную — без автоперестройки при запуске.

**Найдено и исправлено по ходу тестов**
1. `GetComponent<T>() ?? AddComponent<T>()` не работает с «фальшивым null» Unity → окна не получали
   CanvasGroup и не блокировали ввод. Заменено на `TryGetComponent` во всех местах.
2. `SceneManager.sceneLoaded` срабатывал после `SceneContext.Awake` и обнулял ссылку на игрока →
   позиция в реальном мире не сохранялась. Обработчик удалён.
3. URP Particles/Unlit не применял вертексный цвет LineRenderer → bullet line была белой.
   Написан шейдер `SwordArt/FXUnlit`.
4. Боты уничтожали друг друга за ~25 с → снижены точность/урон, урон бот→бот ×0.5; матч теперь длится минуты.
5. Оружие оставалось на экране после смерти; подпись «победитель» при ранней гибели вводила в заблуждение
   → оружие скрывается, показывается «вас устранил: X».
6. Вёрстка магазина (наложение подписи типа), стойки оружия в стене, размер оружия в кадре (FOV оружейной камеры).

Консоль: 0 ошибок компиляции; runtime-ошибок игры нет (единственные сообщения — артефакты тест-харнесса,
