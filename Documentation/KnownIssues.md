# Known Issues & Limitations

## Не проверено автоматически (требует ручной проверки в редакторе)
- **Реальный ввод с клавиатуры/мыши.** Unity в фоне (окно не в фокусе) не обрабатывает player loop и
  отбрасывает события устройств, а отдать фокус окну из скрипта Windows не позволяет. Все механики
  проверены через слой симуляции `GameAction` (те же code paths, что и у реальных action-ов), но сами
  привязки клавиш (WASD/E/R/1-3/Tab/H/мышь) вживую не нажимались.
- **Мини-игра работы**: ввод кодов читает `Keyboard.current` напрямую — проверена логика (старт, оплата,
  бонусы, сохранение), но не набор клавиш вживую.
- **Кнопки UI мышью**: проверены через `Button.onClick.Invoke()`, не кликом курсора.
- **Сборка плеера (Build)** не делалась — только Play Mode в редакторе.

## Ограничения прототипа
- Персонажи — сегментированные low-poly модели с процедурной анимацией, без Humanoid-рига и анимационных клипов
  (структура суставов совместима с будущим ригом).
- Иконки товаров — текстовые глифы вместо спрайтов.
- Звук синтезированный; музыки нет.
- Оружие ботов: бесконечный запас магазинов (ограничен только магазин + перезарядка).
- UI на uGUI `Text` с системным шрифтом Segoe UI (TextMeshPro Essentials не импортированы). На системах без
  Segoe UI используется встроенный LegacyRuntime-шрифт.
- Освещение полностью realtime (без запекания GI) — проще итерации, дороже по GPU.
- Остальные здания города декоративные (двери закрыты); входить можно в квартиру, магазин и лобби офиса.
- Турнир: при гибели игрока матч завершается сразу (без режима наблюдателя).
- Баланс ботов подобран по нескольким прогонам (урон бот→бот ×0.5); может потребовать тонкой настройки
  по ощущениям от живой игры.

## Особенности инструментов / MCP
- `execute_code` (CodeDom, C# 6) не видит `Assembly-CSharp-Editor`, нет локальных функций.
- В тестовых прогонах `EditorApplication.Step()` во время асинхронной загрузки сцены Unity пишет
  «PlayerLoop internal function has been called recursively» — артефакт пошагового тест-харнесса, в обычном
  Play Mode не возникает.
- Скриншоты MCP через камеру не включают Screen Space Overlay UI; для проверки UI канвасы временно
  переключались в Screen Space Camera (только в тестовом сеансе).
- Для автотестов добавлено `SwordArt/Dev/Keep Play Mode Alive` (по умолчанию выключено).
- `PlayerSettings.runInBackground` включён.
- Файл сохранения пользователя (`%USERPROFILE%/AppData/LocalLow/DefaultCompany/SwordArt/savegame.json`) содержит
  прогресс тестовых прогонов; «Новая игра» в меню начинает с чистого листа.
